Maps each reference route or component to its counterpart in this project (spec 0.2 and 0C.6). Reference paths are under `societal-discussion/apps/web/src/app/` in `josesiqueira/manipulative-ai` at commit `6938720847d8f98b7bda7d54f7a82261fa00c6c3`. New paths are under `apps/web/`. Reviewed on 2026-10-03.

Status values: **done** means the page or component exists and was compared with the reference in the independent review of 2026-10-03, by looking at the rendered page (the screenshot named in the row, in `docs/ui-current/`) and at the reference screenshot or, where the reference screenshot shows only a loading state, at the reference source. An **open point** is drift or a defect found in that review that is not an intentional deviation.
